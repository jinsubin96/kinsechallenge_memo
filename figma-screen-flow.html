1체크리스트 참여 플로우

진입

  • Home(챌린지 미참여) → 체크리스트 (웰니스 시그널 발견하기)

화면 순서

체크리스트 main (비로그인 / 로그인)→고민 선택 전→QnA × 5→결과 로딩중→결과 페이지 (최대치 / 안정형)

비로그인일 때 → 회원가입 프로세스 ("챌린지 사이트 로그인 수정")

  • 로그인: 아이디 · 비밀번호, SNS로 회원가입 또는 로그인, 아이디/비밀번호 찾기
  • 정보 입력: 이름(5자 이내), 휴대전화 번호 + 인증번호, 아이디(영문·숫자 8~12자), 비밀번호(영문·숫자·특수문자 8~16자), 비밀번호 확인
  • 약관 동의: 만 14세 이상, 이용약관, 개인정보 처리방침, 광고성 정보 수신(마케팅) — "모두 동의해야 회원가입할 수 있어요"
  • 가입 완료: "회원가입이 완료되었어요! 나에게 맞는 건강한 습관을 찾아봐요."

결과 공유 · 저장

  • 갤러리에 저장: 저장 타입 선택 → 사진으로 공유 (간단히 / 전체)
  • 링크로 공유: 링크 복사 알림 → 결과 페이지(웹링크)
  • 마이페이지에서 결과지 열람: 마이페이지(로그인) → 체크리스트 히스토리 전체 목록 / 필터(닫힘·펼침·드롭다운) / 결과 / 없음
  • 답변 성격 2가지 — 긍정: 선택 시 변화 없음 / 부정: 선택 시 하단 인사이트 팝업 등장
  • 부정 답변 수 = 결과 페이지 '몸이 보내는 신호' 설명 박스 개수. 전부 긍정이면 '안정형' 결과지
  • 하단 공유 버튼 클릭 시 나오는 팝업도 같은 규칙 적용
  • 결과는 마이페이지에 자동 저장
  • 각 화면 일러스트는 움직이는 gif로 들어갈 예정
  • 사진으로 저장하면 인터랙션이 없으므로 hover된 박스 상태로 펼쳐서 나열

2챌린지 참여 전

진입 경로

  • 홈에서 '챌린지 참여하기'
  • 햄버거메뉴
  • 마이페이지
  • 챌린지 목록

화면

  • CRM카카오톡 "새 챌린지 신청이 열렸어요"
  • Home(챌린지 미참여), 햄버거메뉴
  • 마이페이지: 로그아웃 상태 + 진행중인 챌린지 없을 때 / 로그인 상태 · 참여 전 / 챌린지 히스토리 없을 때
  • 챌린지 목록 (진행중 · 종료된 게 없는 경우)
  • 챌린지 개별 화면 – 참여 전 (로그인 후)

신청

챌린지 신청하기→챌린지가 신청되었어요 (서비스 화면)+CRM카카오톡 "챌린지가 신청되었어요"
  • 신청 폼: 본인 인증(이름 · 전화번호, "회원 정보와 동일해요" 버튼 → 가입 정보 자동 입력), 제품 수령 주소, 개인정보 수집 동의, 카카오톡 메시지 수신 동의, 개인정보 제3자 제공 동의
  • "* 제품 수령은 선착순으로 진행돼요."
  • 신청 화면에서 '설명으로 돌아가기' 클릭 시 개별 화면으로 돌아감
  • 챌린지 참여 이력이 있거나 가입 때 광고성 메시지에 동의한 경우 신청 독려 CRM 발송
  • 마이페이지 체크리스트 히스토리는 최신 순 최대 4개, 없을 때는 제목 + 화살표 버튼만
  • 썸네일 아래 기간이 상태에 따라 바뀜 (상태 · 기간 · 일수): 신청 기간 / 진행중 기간 / 종료(진행했던 기간)

3챌린지 신청 후, 시작 전

화면

  • Home – 신청 후, 시작 전
  • 챌린지 개별 화면 – 신청 후, 시작 전
  • 마이페이지 – 로그인 상태 · 참여 전 (신청 후에도 변화 없음)
  • 신청 후 홈 개인화 박스 오른쪽 아래 D-3 → 시작까지 남은 일수
  • 아직 인증이 없을 때는 D-day만 표시
  • 챌린지가 시작되면 관리자가 인증된 사진 중에서 골라 노출

인스타 인증 데이
  • 특정 날짜가 아니라 진행 기간 중 아무 하루에 하면 됨
  • 진행 3일차에 '인스타 공유 데이' 리마인드 CRM 발송
  • 2단계 모두 완료해야 인정: ① 인스타 스토리 업로드 (@kinse_official 태그 + #챌린지명) ② 킨스 사이트에 게시물 URL 공유 (비공개 계정 · 스토리는 캡처 업로드)
  • 완료 문구: "사진 인증 완료했어요! 이대로만 계속, 꾸준히 해봐요:-)"

6챌린지 진행 – 결과 발표

진입 경로

  • CRM 링크
  • 마이페이지

화면

  • CRM카카오톡 "결과 발표되었어요"
  • 성공: 성공 여부 확인 – "완주를 축하합니다" → 기록 확인하기
  • 실패: 성공 여부 확인 – "실패했습니다" → 기록 확인하기
  • CRM카카오톡 "챌린지가 종료되었어요" (성공 화면 접속 시 코드 발송)
  • 챌린지 카드 (default / hover), 마이페이지, 챌린지 히스토리
  • 성공 화면 접속 시 적립금 코드 CRM 발송
  • 기록 확인: 도장을 누르면 그동안 올린 사진 등장 / 업로드하지 않은 날 · 인정되지 않은 날은 우는 얼굴
  • CRM 링크가 아니라 브라우저로 직접 들어오면 마이페이지 챌린지 썸네일에 [결과발표] 표시 → 사용자가 결과를 확인하면 [종료]로 변경
