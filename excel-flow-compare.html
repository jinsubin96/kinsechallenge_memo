같음다름md에만미구현지금 방식 유지

결론

  • 사용자 화면 조건문 기준 = 퍼블 엑셀 + 퍼블 원본
  • 엑셀 조건은 서버에 거의 그대로 들어가 있음
  • 메인 카드 · 상세 비로그인 버튼은 엑셀대로
  • md 는 참고용 — 엑셀과 다른 내용은 반영하지 않음

두 문서의 성격

  • 엑셀 : 퍼블리셔가 개발용으로 넘긴 명세 — 화면 파일별로 어떤 조건에 어떤 클래스 · 문구가 붙는지
  • md : 기획 화면 흐름 — 어디서 들어와 어디로 가는지 + 운영 조건 (CRM · 인스타 인증 데이 등)
  • 겹치는 부분은 대부분 같음

2. 엑셀 · md 가 다른 것

구분항목엑셀md
다름신청 후 시작 전 마이페이지'진행예정(노랑)' 배지로 나의 챌린지에 나옴"신청 후 마이페이지는 변화 없음"지금 : 엑셀대로 진행예정

다름챌린지 목록 기간 표시탭은 on 이동만, 분류는 개발상태별 — 신청 기간 / 진행 기간 / 종료는 진행했던 기간지금 : 신청 기간 기준 분류 (9/28 결정), 종료 카드만 진행 기간

3. md 에만 있는 것

구분항목md 내용지금
