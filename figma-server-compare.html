5. 비어 있는 링크

피그마와 차이는 아니지만 확인하다 보인 것 — 눌러도 이동하지 않습니다(href 비어 있음, 퍼블 원본도 비어 있음).

  • 마이페이지 하단 '약관확인' — 햄버거 메뉴의 약관확인은 연결돼 있는데 마이페이지 쪽만 비어 있음
  • 인증하기 '사진이 안 올라가요!' — 연결할 안내 페이지 필요
  • 성공 화면 '알림톡을 못 받았어요' — 연결할 안내(또는 고객센터) 필요

+ 체크리스트 시작 화면 제목에 "나의"가 두 번 나옴 (나의 / 나의 웰니스 상태 / 체크하기, 10/19 화면 확인)

6. 피그마와 같은 곳

  • 챌린지 목록 탭(전체 · 진행중 · 종료), 카드의 신청 기간 · 일수 · 월 표시, 진행 예정 "What is next? / Comming soon"
  • 챌린지 상세: 신청 기간 띠, 상세 이미지, 햅삐들의 챌린지 인증(사진 6장), 상태별 버튼(신청하기 · 사진 등록하고 인증하기 + "잘 하고 있어요!" 말풍선 · 인증 확인중 · 종료 "다음에 다시 돌아올게요 :-)")
  • 챌린지 신청하기: 본인 인증("회원 정보와 동일해요"), 제품 수령 주소, 동의 3개, 선착순 안내, 신청 완료 화면 문구 · "챌린지 설명으로 돌아가기"
  • 인증하기: 사진 업로드 → 사진 변경 → 인증하기, 도장판, 인증 완료 "사진 인증 완료했어요!" + 갤러리에 저장, 검수중 "지금은 인증할 수 없어요"
  • 결과: 성공 · 실패(추천 루틴) 화면, 내 기록 보기 — 도장을 누르면 그날 사진, 안 올린 날 "업로드하지 않았어요"
  • 마이페이지: 로그인/비로그인 프로필, 나의 챌린지 · 체크리스트 히스토리(최신 4개, 비로그인은 제목만), 빈 상태 문구, 배지 5종(진행중 · 진행예정 · 결과대기중 · 결과발표 · 종료)
  • 체크리스트: 문항 진행바, 부정 답변 시 인사이트, 결과 페이지, 갤러리에 저장(간단히 · 전체), 링크 공유 · 복사 알림, 마이페이지 히스토리 필터
  • 로그인 · 회원가입: SNS 로그인, 약관 동의 4개 + 꼼꼼히 읽었어요, 가입 완료 문구

확인 방법: 서버 FTP 의 사용자 화면 코드와 퍼블 원본(___bakup)을 받아 피그마 화면과 하나씩 대조. 실제 회원 데이터로 화면을 띄워 본 것은 아니라서, 관리자 설정(검사지 · 루틴 · 배너)에 따라 보이는 내용은 달라질 수 있어요.
