회원이 신청하고, 관리자는 제품 운송장을 등록해요

진행기간하루 1장 인증

회원이 매일 사진을 올려요. 이상한 사진은 반려해요

진행기간 끝횟수 부족 탈락

기준만큼 못 올린 회원을 한 번에 탈락시켜요

검수기간검수 · 결과 발표

남은 회원 사진을 확인하고 '최종완료'를 누르면 결과가 정해져요. 발표는 검수기간이 끝난 뒤 한 번에

꼭 알아둘 규칙

  • 인증은 하루 1장이에요. 올린 그날(당일)에만 사진을 다시 골라 바꿀 수 있고, 지난 날 사진은 바꿀 수 없어요. 인증 횟수는 반려되지 않은 사진 수예요. (반려 표시는 검수기간이 끝난 뒤 회원에게 보여요)
  • 성공 기준은 챌린지마다 따로 정해요. (예: 30일 챌린지에 25번 이상 인증하면 성공)
  • 관리자는 사진을 하나하나 승인하지 않아요. 문제 있는 사진만 반려하면 되고, 나머지는 '최종완료' 때 자동으로 승인돼요.
  • 회원의 성공 · 탈락 결과는 관리자가 직접 고를 수 없어요. 아래 두 가지 방법으로만 자동으로 정해져요.
    1. 진행기간이 끝난 뒤 횟수 부족 일괄 탈락 버튼
    2. 검수기간에 심사상태를 최종완료로 바꿀 때
  • 결과가 정해져도 바로 나가지 않고, 검수기간이 끝난 다음 날 모든 회원에게 한 번에 발표돼요. (검수 종료일이 없으면 진행 종료일 다음 날) 그 전까지 회원 화면은 '결과 대기중'이고 반려 표시도 보이지 않아요.

관리자가 하는 일

언제어디서 · 무엇을
준비챌린지 > 챌린지 일정에서 등록
제목, 이미지, 신청기간 · 진행기간 · 검수기간, 성공 인증 횟수(1 ~ 진행 일수, 입력칸 옆에 "최대 N회" 표시 · 넘으면 저장 안 됨), 실패한 회원에게 추천할 루틴
신청기간챌린지 > 신청현황에서 신청자 확인
엑셀로 내려받아 운송장 번호를 채워 다시 올리거나, 목록에서 바로 입력
진행기간챌린지 > 인증현황에서 사진 확인
문제 있는 사진만 체크해서 반려 (잘못 반려했으면 반려 취소)
여러 회원의 사진을 한꺼번에 체크해서 처리할 수도 있어요
진행기간 끝횟수 부족 일괄 탈락 버튼 클릭
사진을 기준보다 적게 올린 회원(한 번도 안 올린 회원 포함)이 한 번에 탈락돼요 → 회원에게는 검수기간이 끝난 뒤 실패 결과
검수기간남은 회원 사진을 확인하고 필요하면 반려
확인이 끝난 회원을 체크해 심사상태를 최종완료로 변경 → 결과가 자동으로 정해짐 (회원 발표는 검수기간이 끝난 다음 날 모든 회원 한 번에)

※ '최종완료'와 '횟수 부족 일괄 탈락'은 진행기간이 끝나야 누를 수 있어요. 최종완료된 회원의 사진은 반려할 수 없어요(심사중으로 되돌린 뒤 처리).

결과는 이렇게 정해져요

결과언제 이렇게 되나요
성공반려되지 않은 사진이 성공 기준 이상
탈락(반려)올린 횟수는 충분했는데, 반려된 사진 때문에 기준에 못 미침
탈락(횟수 부족)올린 횟수 자체가 기준보다 적음
결과 대기아직 결과가 정해지지 않음 (회원에게는 '결과 대기중')

※ 성공 기준을 바꾼 뒤 결과를 다시 받고 싶으면, 심사상태를 '심사중'으로 바꿨다가 다시 '최종완료'로 바꾸면 돼요.

언제회원이 보는 것
신청기간 전상세에 카드 · 버튼 없음 (목록 카드는 눌리지 않음)
신청기간"챌린지 신청하기" 버튼 (로그인 안 했으면 "로그인 후 신청하기")
이름 · 전화번호 · 주소 입력, 동의 3개 체크 후 신청

진행기간"사진 등록하고 인증하기" → 하루 1장 업로드
오늘 올린 뒤 다시 들어오면 오늘 사진이 보이고, 그날에만 다시 골라 바꿀 수 있어요 (버튼은 항상 "인증하기")
도장판에 인증한 날 · 놓친 날 · 오늘이 표시돼요
검수기간"결과 대기중이에요" (사진은 더 올릴 수 없어요)
관리자가 결과를 정해도 검수기간 동안은 이 화면 그대로
검수기간 끝 (결과 발표)모든 회원에게 한 번에 — 성공 → "챌린지 성공했어요!" + 리워드 안내
탈락 → "완주하지 못했어요" + 추천 루틴
두 화면 모두 "내 기록 보기"로 도장판 확인 (사진 왼쪽 위 도장 : 승인 웃는 얼굴 / 반려 · 안 올린 날 우는 얼굴)
검수기간 끝 · 결과 없음"종료된 챌린지 · 다음에 다시 돌아올게요" (신청 안 한 회원 · 결과가 정해지지 않은 회원)

※ 승인 · 반려 도장이 보이는 내 기록은 결과 발표 뒤에만 열려요 : 나의 챌린지 결과발표 카드 또는 사진 인증 주소 → 결과 화면(성공 / 실패) → 내 기록 보기. 발표 전에는 "아직 결과가 발표되지 않았어요." 안내 후 인증하기 화면으로 가요.

※ 마이페이지 '나의 챌린지'에는 진행중 / 진행예정 / 결과대기중(검수기간) / 결과발표(검수기간이 끝나고 결과가 있음) / 종료(결과 없음) 중 하나가 표시돼요.

정해야 할 것

  1. 결과 화면이 '완주'라는 표현을 쓰는데, 성공 기준이 'N번 이상'이라 뜻이 안 맞아요. 회원 화면에 성공 기준 안내도 없어요.
