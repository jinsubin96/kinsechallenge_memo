언제 발표되나

  • 검수기간이 끝난 다음 날 모든 회원에게 한 번에 발표 (검수 종료일이 없으면 진행 종료일 다음 날). 결과는 관리자 인증현황의 챌린지 결과 값 (진행기간 뒤 횟수 부족 일괄 탈락 · 검수기간 최종완료) — 10/19 저녁 변경, 전에는 정해지면 바로 발표
  • 마이페이지 결과발표 카드 → 성공 또는 실패 화면 (발표 전에는 인증하기 화면)
  • 내 기록 가는 길 : 나의 챌린지 결과발표 카드 또는 사진 인증 주소 → 결과 화면(성공 / 실패) → 내 기록 보기. 발표 전에 주소로 들어오면 아직 결과가 발표되지 않았어요. → 인증하기 화면, 검수기간이 끝났는데 결과가 없는 회원은 들어갈 수 없음
